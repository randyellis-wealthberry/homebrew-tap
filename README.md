# Wealthberry Labs Homebrew tap

```bash
brew install randyellis-wealthberry/tap/inkwell-daily
```

## Inkwell Daily

A morning newspaper about yesterday's agent work, commits, and weather, set
from your own Mac.

```bash
inkwell-daily install   # the morning run, at 5 by default
inkwell-daily build     # yesterday's edition
inkwell-daily open
```

Source and docs: <https://github.com/randyellis-wealthberry/inkwell-daily>
